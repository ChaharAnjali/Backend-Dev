# Answers

## 1. Online Banking System

Database Type: SQL  
Justification:
- Structured data
- ACID properties required
- High security and consistency

---

## 2. Social Media Platform
Database Type: NoSQL  
Justification:
- Unstructured data
- High scalability
- Flexible schema

---

## 3. Real-time Chat Application
Database Type: NoSQL  
Justification:
- Fast read/write
- Real-time communication
- Scalable

---

## 4. Hospital Patient Records
Database Type: SQL  
Justification:
- Structured records
- Data integrity important
- Secure and consistent

---

## 5. IoT Sensor Data Collection
Database Type: NoSQL  
Justification:
- Large volume of data
- Continuous streaming
- Flexible schema
